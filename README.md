# Timezones

Simple timezones widget for Windows, built with Python.

TimeZones.exe is located in [releases](https://github.com/Saif-Quazi/TimeZones/releases)

## Local Setup

Install dependencies:
```
pip install -r requirements.txt
```
Run locally:
```
python main.py
```
